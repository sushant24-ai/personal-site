LinkedIn images need to be saved locally. Use this tool to generate markdown for your images:

📥 Quick Steps to Import LinkedIn Images:

  1. Right-click each image in your LinkedIn article → "Save image as..."
  2. Save to: personal-site/assets/images/
  3. Name it descriptively (e.g., istio-architecture.png)
  4. Use the tool above to generate the markdown
  5. Replace No alt text provided for this image in your content with the generated markdown
