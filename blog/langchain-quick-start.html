LangChain #2: Quick Start

December 20, 2023 LangChain OpenAI Python

In this chapter, we delve into the practical aspects of implementing cutting-edge language models using LangChain. We'll focus on the straightforward integration of three distinct models: OpenAI, HuggingFace, and Gemini.

🚀 Querying OpenAI, HuggingFace, and Gemini

Let's get hands-on with LangChain by connecting to three popular LLM providers. By the end of this guide, you'll be able to query any of these models with just a few lines of code.

🔷 OpenAI

First, install the OpenAI package:

pip install openai langchain

Get your API key from OpenAI's website. Then set it as an environment variable — this is a common practice to keep credentials out of your source code. 

import os
os.environ["OPENAI_API_KEY"] = "your-api-key"

Now let's use LangChain to query OpenAI:

from langchain.llms import OpenAI

# Initialize the model
llm = OpenAI(model="gpt-3.5-turbo-instruct")

# Make a query
query = "Explain the process of photosynthesis in detail."
answer = llm(query)

print(answer)

Output:

Photosynthesis is the process by which plants, algae, and some bacteria 
convert light energy from the sun into chemical energy stored in the form 
of glucose. This process is essential for all plant life and is responsible 
for the presence of oxygen in the Earth's atmosphere.

The process requires three primary components: light, carbon dioxide, and water...

🤗 HuggingFace

HuggingFace gives you access to thousands of open-source models. Install the package:

pip install huggingface-hub

Get your API token from HuggingFace settings:

os.environ["HUGGINGFACEHUB_API_TOKEN"] = "your-huggingface-token"

Now query a model from HuggingFace Hub:

from langchain.llms import HuggingFaceHub

# Use Google's FLAN-T5 model
llm = HuggingFaceHub(repo_id="google/flan-t5-xxl")

query = "Explain the process of photosynthesis in detail."
answer = llm(query)

print(answer)

Output:

The process of photosynthesis is the conversion of light energy into chemical energy.
Note: Open-source models may give shorter or less detailed answers compared to proprietary models like GPT-4. Choose based on your use case and budget!

💎 Gemini

Google's Gemini is another powerful option. Install the required packages:

pip install langchain-google-genai google-generativeai

Get your API key from Google AI Studio:

os.environ["GOOGLE_API_KEY"] = "your-google-api-key"

import google.generativeai as genai
genai.configure(api_key=os.environ.get("GOOGLE_API_KEY"))

Query Gemini through LangChain:

from langchain_google_genai import ChatGoogleGenerativeAI

llm = ChatGoogleGenerativeAI(model="gemini-pro")

result = llm.invoke("Explain the process of photosynthesis in detail.")
print(result.content)

Output:

Photosynthesis is the process by which plants and other organisms use sunlight 
to convert carbon dioxide and water into oxygen and energy in the form of sugar.

The overall equation for photosynthesis is:
